# 深夜0時の生中継

企画スライドを基に、Uno Engine / DirectX 12上で制作した一人用ホラーゲームです。
黒電話を回して1989年の茶の間を「話し中」にし、ヒロシを番組の電話から守ります。
第二幕では調査先を選び、数字でミドリを動かしてテレビを止めます。

## 起動

`build/game/MidnightLive_build/MidnightLive.exe` を起動してください。
同じフォルダーにある `game.pak` とDLLも必要です。配布時はフォルダー全体を渡します。

タイトルの「放送を始める」が通常版、「三分の短縮版」が確認用です。
短縮版も同じルール・物語・結末ですが、放送時計が5倍で進みます。
受話器と回転ダイヤルは、短縮版でも実時間で動きます。着信予告はその操作時間を見込んで早めに出ます。
救出に成功した場合や失敗した場合は、15分より早く終了します。

このリポジトリにはゲームのソースと素材を収録しています。エンジン本体・依存DLL・ビルド出力は含みません。
Uno Engine v2.6.1を用意し、エディタから `FL1.dx12proj` を開き、`scenes/midnight.json` をPlayします。
元のテンプレートシーン `scenes/main.json` は残しています。

## 操作

| 操作 | マウス | キー |
|---|---|---|
| 通常版を開始 | 放送を始める | Enter |
| 短縮版を開始 | 三分のボタン | Q |
| 受話器を取る／戻す | 受話器そのもの、または受話器ボタン | E（UI選択中以外はSpaceでも可） |
| 数字を回す | 黒電話の数字 | 数字列またはテンキー0〜9 |
| 受話器を戻して番号を消す | 受話器ボタン | Backspace |
| メモを開く／閉じる | メモボタン | Tab |
| 一時停止／再開 | 一時停止画面のボタン | Esc |
| 音のオン／オフ | — | M |
| 結末からタイトルへ | タイトルへ戻る | Enter |

ダイヤルが戻るまで、次の数字は入力できません。0は最も時間がかかります。
指で回す動き→一定速の戻り→数字の送信の順に進みます。数字は指穴の中央に表示し、回転中は中央の表示へ切り替えます。
電話をかけ直すときは受話器を一度戻してください。マイク・カメラは使いません。
メモと一時停止を開いている間は、放送時計が止まります。

## 最初の目標

机のメモの番号へ、番組より先に電話をかけてください。
通話が成立した間だけ家の回線を守れます。ダイヤル中や呼出中は無防備です。
ヒロシが切ったら、受話器を戻してかけ直します。
番組が家につながるとヒロシが一歩ずつ近づき、三回で連れ去られます。

第二幕では父の会社と隣家で調査、117で次の着信時刻を確認できます。
画面上端には番組の発信予告とカウントダウンが出ます。通常版は20秒前から予告されます。
117の調査後は、次の発信までの時間を予告前から確認できます。
「回線保護中」「遮断成功」「番組がつながった」を別々に表示します。
数字によるミドリへの指示は、子どもの家との通話中に行います。
数字を聞かれすぎると、番組があなたの番号を回し始めます。
目の前の黒電話が鳴ったあとの、受話器の扱いに注意してください。

## 構成と再生成

- `assets/scripts/midnight_core.lua`：電話・放送時計・調査・分岐。エンジンに依存しないルール。
- `assets/scripts/midnight_adapter.lua`：エンジンのUI・入力・音・人物アニメーション。
- `assets/scripts/midnight_feedback.lua`：受話器・人物の移動量管理、回転ダイヤルの角度。
- `tools/style_game.mjs`：各画面の配色・文字・余白・ボタン状態。
- `tools/preview_scene.mjs`：四結末と第二幕の静止プレビュー。
- `tools/build_game.mjs`：ルール・フィードバック・アダプターのLuaを結合し、編集可能なUIシーンの元JSONを生成。
- `assets/components/MidnightGame.lua`：実行用に生成したLuaコンポーネント。
- `assets/scenes/midnight.json`：MCPで検証・書き込みしたゲームシーン。
- `tools/make_audio.py`：数字別のダイヤル、発信音・呼出音・話中音、番組予告など27種のWAVを生成。
- `tools/make_voices.ps1`：Windows日本語音声で試作用の台詞音声22本を生成。
- `tests/midnight_core_test.lua`：19項目のルール・通し進行テスト。
- `tests/midnight_feedback_test.lua`：受話器の位置ずれ、連打、数字の回転、予告時間等の10項目。
- `docs/POLISH.md`：0.4.0の画面設計と変更内容。
- `docs/VERIFICATION.md`：検証の範囲と結果。

`node tools/build_game.mjs` の生成先は `docs/generated/midnight_scene.json` です。
編集後はMCP `dx12_create_lua_component` で構文検証し、`dx12_scene_write` でそのJSONを
`scenes/midnight.json` に書き込んで開きます。シーンへ手作業で加えた変更は、再生成時に取り込んでください。

Luaテストは、Pythonで次を実行します（ルール19項目とフィードバック10項目）。

```text
python tools/run_lua_tests.py tests/midnight_core_test.lua
python tools/run_lua_tests.py tests/midnight_feedback_test.lua
```
`UNO_ENGINE_DIR` を設定すると別のエンジン配布先の `lua.dll` を利用できます。

## 実機との接続について

今回は「未接続、まずPCで遊べる状態」という指定に合わせ、PC版を完成対象にしています。
実機の配線・ESP32への書き込み・ベル駆動・ブラウン管への映像出力は検証していません。

入力アダプターはエンジンの `hw.device('midnight_phone')` に対応しています。
将来のファームウェアでは `hook`（1=受話器を上げた）、`digit`（最後に回した0〜9）、
`sequence`（一桁の回転が完了するたび増える整数）を入力します。
`bell` は出力で、着信中1、それ以外・終了・停止時0です。
実機側でもエンジン切断時の安全出力を0に設定します。

企画資料にない子どもの家の番号、部屋指示、時間調整値、具体的な結末名は今回の仮設定です。
美術・フォント・合成音声・画像生成プロンプトの出典は `docs/ASSET_CREDITS.md` に記録しています。
