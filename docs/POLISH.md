# 0.4.0 デザイン更新

電話で過去を「話し中」にし、調査と数字の指示で子どもを救う構成へ戻した。
0.3.0で試した廊下の監視、人影、扉、灯り、予備電源のルール・操作・UI・専用効果音を削除。

## 画面ごとの変更

- タイトル：二行の作品名と開始操作を左、1989年の茶の間を右に配置。主操作は明るい紙色、短縮版は枠線で区別。
- プレイ：テレビ・字幕・電話帳・回線状態・黒電話・次の目標に領域を分けた。第一幕は真鍮色、第二幕は淡い緑の目印。
- メモ：防衛と調査の二段組み。部屋指示、判明済みの手掛かり、警告、再開操作を独立して配置。
- 一時停止：中央パネルに再開とタイトル復帰を並べ、操作の優先順位を明確にした。
- 四つの結末：左に結末と記録、右に茶の間の写真。結末ごとに写真の色調と余韻の一文を変える。

配色・余白・ボタンの通常/ホバー/押下状態は `tools/style_game.mjs` に集約。
UIの文字は画像へ焼き込まず、ネイティブテキストのまま編集できる。

## 維持した修正

受話器は一つの親を上下させ、相対移動量の積み重なりを防ぐ。
数字は全10個とも指穴と同じ中心に配置。回転中は固定の数字板を隠し、中央に入力中の数字を表示。
数字別の機械音、発信音・呼出音・話中音、番組の発信予告とカウントダウンを維持。
短縮版でも電話の機械動作は実時間で進む。

## 公開リポジトリ

ソース、ゲーム素材、生成ツール、テスト、利用方法と素材出典を管理。
エンジン本体とDLL、ビルド出力、ユーザー設定、キャッシュ、原企画資料は含めない。
