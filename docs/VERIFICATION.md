# 0.4.0 検証記録

## ゲームルール

Uno Engineと同じLua DLLをPython ctypesから呼び出し、ルール19項目、機械動作・予告10項目、計29項目がPASS。
通常版/短縮版、電話の保護、三回の失敗、調査、移動、発覚、着信応答、四結末を含む。
防衛5回から調査・誘導・救出までの通しシナリオも実行した。
受話器100往復、移動中の反転、リセット、人物の往復、全数字の回転と短縮版の予告猶予を検証。

## デザイン確認

タイトル・プレイ画面・メモ・一時停止をエンジンで表示し、文字と操作領域を確認。
四結末は `tools/preview_scene.mjs` の静止プレビューで、それぞれの結末文と写真を表示して確認。
四結末のstrict UI監査はエラー0・警告0。
プレイ画面の監査は、実形状を保った44×44の指穴10個だけが推奨72×44未満として検出される。
数字キーとテンキーでも操作できる。監査の全項目PASSとはしていない。
タイトルの電話帳、プレイ画面の番号表示で検出された高さ不足は修正した。
スクリプトエラー0件。静止プレビューは本番シーンへ戻し、配布アセットから除去。
更新したPC単体ビルドでも、タイトル、開始、受話器、数字3の直接クリック、メモ、再開、一時停止、タイトル復帰を確認。
廊下・扉・灯り・予備電源のUIがないことも確認した。

## 範囲

実物の黒電話・ESP32・CRTは未接続。PCのキーボードとUIを対象にした。
通常版15分の全実時間プレイは行わず、Luaの通しシナリオと画面別の実操作で確認。
台詞は試作用の合成音声で、一部の動的な台詞は字幕のみ。
エンジンと依存DLLは外部のUno Engine配布物。ソースリポジトリには含めない。
